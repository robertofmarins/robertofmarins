### 🚀 [ChamaKi — Plataforma SaaS de Inteligência Operacional](https://www.chamaki.app) *(Repositório Privado)*
*Sistema completo de comando operacional e financeiro para estabelecimentos gastronômicos (SaaS).*
* **Tecnologias:** Next.js • Tailwind CSS • TypeScript • Node.js • PostgreSQL • Supabase • Drizzle ORM • Sentry
* **Arquitetura & Segurança:** Implementação de arquitetura *Multi-tenant* utilizando *Row Level Security (RLS)* no PostgreSQL para isolamento completo e seguro dos dados de cada cliente.
* **Inteligência Financeira:** Módulo de Ficha Técnica que realiza o cálculo automático da lucratividade real de cada prato e gera snapshots de custo histórico no momento da venda.
* **Operação:** Gestão de pedidos em tempo real com controle de fluxo, alertas sonoros e geolocalização integrada para cálculo inteligente de frete e proteção anti-fraude em pedidos via QR Code.
